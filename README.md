# Admin System Frontend

Admin Dashboard built with Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, and lucide-animated.

# Features

- Sign In, Sign Up
- Admin Dashboard
- User Management CRUD
- Employee Profile
- Dark and Light Mode
- Responsive UI
- Cookie-Based Authentication

# Installation

1. Clone the frontend repository.
2. Open the folder in VS Code.
3. Install dependencies: npm install
4. Create `.env.local`: NEXT_PUBLIC_API_URL=http://localhost:8000
5. Start the application: npm run dev
6. Open http://localhost:3000

# Routes

- / - Sign In
- /sign-up - Sign Up
- /dashboard - Dashboard
- /user - User Management
- /profile - Employee Profile
